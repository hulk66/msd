# Training session outline (~90 minutes)

Audience: msd.com content team. Format: hands-on, real migrated pages.

## Part 1 — How the site works (15 min)
- A page = a Google Doc. Publishing flow: edit → preview → publish.
- Show a real migrated Doc next to its live page side by side.

## Part 2 — Everyday edits (20 min)
- Edit a paragraph and a heading; preview; publish.
- Replace an image; add alt text.

## Part 3 — Blocks (30 min)
- Walk through the guide's block table using real pages.
- Hands-on: add a card to a cards block; add an accordion entry; flip a
  content-block with `right`; give a section a dark background.

## Part 4 — Safety nets (15 min)
- Preview before publish — the rule.
- Revert via Sidekick publish history (live demo).
- When to ask a developer; where the guide lives.

## Exercise (15 min, editors do it themselves)
1. Open your assigned practice Doc.
2. Change the hero headline and button link.
3. Add one card to the cards block.
4. Add a `quote` block with attribution.
5. Preview, then publish.
6. Revert the publish. Re-publish the corrected version.

Completion: all six steps done without help.
